# SMI
Sistem Manajemen Inventori adalah aplikasi desktop berbasis Java untuk mengelola produk, kategori, supplier, stok masuk-keluar, dan riwayat transaksi. Aplikasi ini membantu pengguna memantau ketersediaan barang, mencatat perubahan stok secara terstruktur, serta menyediakan informasi dan laporan inventori untuk mempermudah pengelolaan persediaan
